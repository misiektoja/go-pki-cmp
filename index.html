    go-pki-cmp¶

    go-pki-cmp is a Go library for the Certificate Management Protocol (CMP). It has four packages:

    • pkicmp encodes, parses, protects and verifies CMP and CRMF messages
    • client enrolls, updates and revokes certificates and asks a CA for information
    • server serves the same operations to CMP clients as an http.Handler in front of your CA
    • cms encrypts and decrypts the CMS EnvelopedData and EncryptedValue that proof of possession by decryption needs

    The server handles the protocol: transport, message protection, transactions, polling and certificate confirmation. Your application supplies issuance, credential lookup and authorization policy through Go interfaces. cmp-issuer, a cert-manager external issuer, is built on this library.

    Certificates can carry post-quantum ML-DSA, SLH-DSA or composite ML-DSA keys and all of them can sign CMP messages. ML-KEM keys are certified through proof of possession by decryption. The support matrix lists what is covered.

    Install¶

    go get github.com/misiektoja/go-pki-cmp

    The module needs Go 1.27.3 or newer. Releases up to v0.3.2 use the module path github.com/misiektoja/go-pkicmp-ng.

    Start here¶

    Getting started runs the example CA and client from the repository. The client enrolls with a shared secret, updates its key and revokes the result. The page then names each piece you replace in your own client or server.

    Credits¶

    go-pki-cmp began as a fork of tsaarni/go-pkicmp by Tero Saarni. Its package layout, ASN.1 types and client and server design come from that project. The NOTICE file records the attribution.
